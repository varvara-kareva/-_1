## Краткая теория

**Цифры числа** выделяются с помощью операций целочисленного деления `/` и взятия остатка `%` от деления на 10:
- `num % 10` — последняя цифра числа;
- `num / 10` — отбрасывает последнюю цифру.

Цикл повторяется, пока число не станет равным 0 — так получаем все цифры.

**Массив** — набор однотипных элементов, объявленный как `int arr[100];`. Доступ к элементу — `arr[i]` (индекс с 0).

**Транспонирование** матрицы — обмен строк и столбцов: элемент `A[i][j]` становится элементом `T[j][i]`.

**Сортировка вставками** — каждый элемент последовательно вставляется на своё место в уже отсортированную часть массива.

**Палиндром** — последовательность, читающаяся одинаково слева направо и справа налево.

## 1. Задача «Числа Падована»

### Постановка задачи

Организовать и распечатать последовательность чисел Падована, не превосходящих число `m`, введённого с клавиатуры.
Ряд чисел Падована: `1, 1, 1, 2, 2, 3, 4, 5, 7, 9, 12, 16, 21, 28, 37, 49, ...`

Формула: `P(0) = P(1) = P(2) = 1`, `P(n) = P(n-2) + P(n-3)`.

**Требования:**
1. Использовать цикл `for`.
2. Использовать простую условную конструкцию `if ... else`.
3. **Запрещено** просто распечатать первые три единицы как строку — они должны быть частью алгоритмического решения.

### Математическая модель

Числа Падована задаются рекуррентно: каждый следующий элемент равен сумме элементов на третьей и второй позициях назад.

```
P(0)=1, P(1)=1, P(2)=1
P(n) = P(n-2) + P(n-3)  для n >= 3
```

Храним три последних элемента `a, b, c` (текущий и два предыдущих). Следующий элемент вычисляется как `a + b`, затем сдвигаем окно: `a = b; b = c; c = next`. Цикл продолжается, пока следующий элемент не превысит `m`.

### Список идентификаторов

| Имя переменной | Тип данных | Смысловое обозначение |
|---|---|---|
| `m` | `long long` | Верхняя граница последовательности (вводится с клавиатуры) |
| `a` | `long long` | Третий с конца элемент |
| `b` | `long long` | Второй с конца элемент |
| `c` | `long long` | Последний элемент |
| `next` | `long long` | Очередной вычисляемый элемент |

### Код программы

```c
#include <stdio.h>

int main(void)
{
    long long m;
    printf("Введите m: ");
    scanf("%lld", &m);

    long long a = 1, b = 1, c = 1;

    printf("Числа Падована, не превосходящие %lld:\n", m);
    printf("1 1 1 ");

    long long next;
    for (next = a + b; next <= m; next = a + b) {
        printf("%lld ", next);
        a = b;
        b = c;
        c = next;
    }
    printf("\n");
    return 0;
}
```

### Результаты выполненной работы

```
Введите m: 50
Числа Падована, не превосходящие 50:
1 1 1 2 2 3 4 5 7 9 12 16 21 28 37 49
```

**Пояснение:** при `m = 50` программа вывела все числа Падована до `49`. Первые три единицы получены алгоритмически (начальные значения переменных `a, b, c`), а не напечатаны строкой как «1 1 1» без вычислений. Очередное число вычислено как `a + b`.

## 2. Задача «Сумма цифр положительного числа»

### Постановка задачи

С клавиатуры вводится произвольное целое положительное число. Программа вычисляет сумму его цифр.
- Если сумма цифр `> 10` — вводится следующее число.
- Если сумма цифр `≤ 10` — программа завершается.

Для разделения числа на цифры использовать целочисленное деление `/` и взятие остатка `%`.

### Математическая модель

Чтобы найти сумму цифр, извлекаем цифры справа налево:
1. `sum += num % 10` — добавить последнюю цифру.
2. `num = num / 10` — отбросить последнюю цифру.
3. Повторять, пока `num > 0`.

После вычисления суммы проверяем условие `sum > 10` (повторный ввод) или `sum <= 10` (завершение). Подходит цикл `do...while`, так как хотя бы один ввод нужен всегда.

### Список идентификаторов

| Имя переменной | Тип данных | Смысловое обозначение |
|---|---|---|
| `num` | `int` | Введённое число |
| `sum` | `int` | Сумма цифр числа |
| `t` | `int` | Рабочая копия числа для цикла |

### Код программы

```c
#include <stdio.h>

int main(void)
{
    int num;
    int sum;

    do {
        printf("Введите положительное целое число: ");
        scanf("%d", &num);

        if (num < 0) {
            printf("Число должно быть положительным. Повторите ввод.\n");
            continue;
        }

        sum = 0;
        int t = num;
        while (t > 0) {
            sum += t % 10;
            t /= 10;
        }

        printf("Сумма цифр числа %d равна %d\n", num, sum);
    } while (sum > 10);

    printf("Сумма цифр <= 10, программа завершена.\n");
    return 0;
}
```

### Результаты выполненной работы

```
Введите положительное целое число: 1234
Сумма цифр числа 1234 равна 10
Сумма цифр <= 10, программа завершена.
```

**Пояснение:** для числа `1234` сумма цифр `1+2+3+4 = 10`. Так как `10 <= 10`, условие `sum > 10` ложно, и цикл завершается. Если бы сумма была больше 10, программа запросила бы следующее число.

## 3. Массивы. Задача 1. Квадраты элементов, среднее арифметическое, подсчёт

### Постановка задачи

Для числового вектора `X`, введённого с клавиатуры:
1. Вычислить вектор `Y`, где каждый элемент `y_i = x_i²`.
2. Найти среднее арифметическое элементов вектора `Y`.
3. Определить количество элементов вектора `Y`, превышающих среднее значение.

### Математическая модель

Пусть `n` — число элементов. Для каждого `i`:
- `Y[i] = X[i] * X[i]`;
- накапливаем сумму `sum += Y[i]`.

Среднее арифметическое: `average = sum / n`.

Затем проходим по массиву `Y` и считаем элементы, для которых `Y[i] > average`.

### Список идентификаторов

| Имя переменной | Тип данных | Смысловое обозначение |
|---|---|---|
| `n` | `int` | Количество элементов |
| `X` | `double[100]` | Исходный вектор |
| `Y` | `double[100]` | Вектор квадратов элементов |
| `sum` | `double` | Сумма элементов вектора Y |
| `average` | `double` | Среднее арифметическое |
| `count` | `int` | Количество элементов Y, превышающих среднее |
| `i` | `int` | Индекс / счётчик цикла |

### Код программы

```c
#include <stdio.h>

int main(void)
{
    int n;
    printf("Введите количество элементов вектора X: ");
    scanf("%d", &n);

    double X[100], Y[100];
    double sum = 0.0;

    printf("Введите %d элементов X:\n", n);
    for (int i = 0; i < n; i++) {
        scanf("%lf", &X[i]);
        Y[i] = X[i] * X[i];
        sum += Y[i];
    }

    double average = sum / n;

    int count = 0;
    for (int i = 0; i < n; i++) {
        if (Y[i] > average) {
            count++;
        }
    }

    printf("Вектор Y (квадраты):\n");
    for (int i = 0; i < n; i++) {
        printf("%.2f ", Y[i]);
    }
    printf("\n");

    printf("Среднее арифметическое Y: %.2f\n", average);
    printf("Элементов Y, превышающих среднее: %d\n", count);
    return 0;
}
```

### Результаты выполненной работы

```
Введите количество элементов вектора X: 4
Введите 4 элементов X:
1 2 3 4
Вектор Y (квадраты):
1.00 4.00 9.00 16.00
Среднее арифметическое Y: 7.50
Элементов Y, превышающих среднее: 2
```

**Пояснение:** для `X = {1,2,3,4}` квадраты `Y = {1,4,9,16}`. Среднее `(1+4+9+16)/4 = 30/4 = 7.5`. Элементы `9` и `16` больше среднего — их 2.

## 4. Массивы. Задача 2. Обратный порядок элементов массива

### Постановка задачи

Для числового массива `X`, вводимого с клавиатуры поэлементно, изменить порядок элементов на обратный и вывести результат на экран.

### Математическая модель

Обмен элементов симметрично относительно центра массива. Ставим два индекса `i = 0` и `j = n - 1`. Пока `i < j`, меняем местами `X[i]` и `X[j]`, затем `i++`, `j--`. Для массива из `n` элементов выполняется `n/2` обменов.

### Список идентификаторов

| Имя переменной | Тип данных | Смысловое обозначение |
|---|---|---|
| `n` | `int` | Количество элементов |
| `X` | `int[100]` | Массив |
| `i`, `j` | `int` | Индексы с начала и с конца |
| `temp` | `int` | Временная переменная для обмена |

### Код программы

```c
#include <stdio.h>

int main(void)
{
    int n;
    printf("Введите количество элементов: ");
    scanf("%d", &n);

    int X[100];
    printf("Введите %d элементов:\n", n);
    for (int i = 0; i < n; i++) {
        scanf("%d", &X[i]);
    }

    for (int i = 0, j = n - 1; i < j; i++, j--) {
        int temp = X[i];
        X[i] = X[j];
        X[j] = temp;
    }

    printf("Массив в обратном порядке:\n");
    for (int i = 0; i < n; i++) {
        printf("%d ", X[i]);
    }
    printf("\n");
    return 0;
}
```

### Результаты выполненной работы

```
Введите количество элементов: 5
Введите 5 элементов:
1 2 3 4 5
Массив в обратном порядке:
5 4 3 2 1
```

**Пояснение:** элементы массива обменяны симметрично: первый с последним, второй с предпоследним и т.д. Получен массив `5 4 3 2 1`.

## 5. Массивы. Задача 3. Транспонирование матрицы

### Постановка задачи

Транспонировать матрицу:

```
A = | 1 2 3 |
    | 4 5 6 |
    | 7 8 9 |
```

Транспонирование — замена строк на столбцы.

### Математическая модель

Элемент матрицы `A` в строке `i` и столбце `j` становится элементом транспонированной матрицы `T` в строке `j` и столбце `i`:

```
T[j][i] = A[i][j]
```

Для матрицы 3×3 ответом будет матрица, у которой главная диагональ `1,5,9` не меняется, а остальные элементы меняются местами симметрично.

### Список идентификаторов

| Имя переменной | Тип данных | Смысловое обозначение |
|---|---|---|
| `A` | `int[3][3]` | Исходная матрица |
| `T` | `int[3][3]` | Транспонированная матрица |
| `i`, `j` | `int` | Индексы строки и столбца |

### Код программы

```c
#include <stdio.h>

int main(void)
{
    int A[3][3] = {
        {1, 2, 3},
        {4, 5, 6},
        {7, 8, 9}
    };

    printf("Исходная матрица A:\n");
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            printf("%d ", A[i][j]);
        }
        printf("\n");
    }

    int T[3][3];
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            T[j][i] = A[i][j];
        }
    }

    printf("\nТранспонированная матрица:\n");
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            printf("%d ", T[i][j]);
        }
        printf("\n");
    }
    return 0;
}
```

### Результаты выполненной работы

```
Исходная матрица A:
1 2 3
4 5 6
7 8 9

Транспонированная матрица:
1 4 7
2 5 8
3 6 9
```

**Пояснение:** строки стали столбцами. Первая строка исходной `1 2 3` стала первым столбцом `1 4 7`, и т.д. Диагональ `1 5 9` не изменилась.

## 6. Массивы. Задача 4. Сортировка вставками (внутри main)

### Постановка задачи

Самостоятельно реализовать алгоритм сортировки **вставками** без создания собственных функций, внутри функции `main`.

### Математическая модель

Сортировка вставками: массив условно делится на отсортированную (левая часть) и неотсортированную (правая часть). На каждом шаге берём очередной элемент `key` и сдвигаем вправо все элементы отсортированной части, которые больше `key`, затем ставим `key` на освободившееся место.

```
для i от 1 до n-1:
    key = arr[i]
    j = i - 1
    пока j >= 0 и arr[j] > key:
        arr[j+1] = arr[j]
        j--
    arr[j+1] = key
```

### Список идентификаторов

| Имя переменной | Тип данных | Смысловое обозначение |
|---|---|---|
| `n` | `int` | Количество элементов |
| `arr` | `int[100]` | Массив |
| `i` | `int` | Индекс текущего элемента (счётчик внешнего цикла) |
| `j` | `int` | Индекс при вставке |
| `key` | `int` | Текущий вставляемый элемент |

### Код программы

```c
#include <stdio.h>

int main(void)
{
    int n;
    printf("Введите количество элементов: ");
    scanf("%d", &n);

    int arr[100];
    printf("Введите %d элементов:\n", n);
    for (int i = 0; i < n; i++) {
        scanf("%d", &arr[i]);
    }

    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }

    printf("Отсортированный массив (вставками):\n");
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
    return 0;
}
```

### Результаты выполненной работы

```
Введите количество элементов: 6
Введите 6 элементов:
5 2 8 1 9 3
Отсортированный массив (вставками):
1 2 3 5 8 9
```

**Пояснение:** массив `5 2 8 1 9 3` отсортирован по возрастанию в `1 2 3 5 8 9`. Каждый элемент вставлялся на своё место путём сдвига больших элементов вправо. Весь алгоритм выполнен внутри `main`, без отдельных функций и без `sort`.

## 7. Массивы. Задача 5. Палиндром и второй по величине элемент

### Постановка задачи

Дан массив целых чисел `A`, вводимый с клавиатуры. Требуется:
1. Определить, является ли массив палиндромом (читается одинаково слева направо и справа налево).
2. Найти второй по величине элемент в массиве. Если все элементы одинаковы — вывести соответствующее сообщение.

### Математическая модель

**Палиндром:** сравниваем элементы попарно с двух концов: `arr[i]` и `arr[n-1-i]`. Если все пары равны — палиндром.

**Второй по величине:** поддерживаем два значения — максимум `first` и второй максимум `second`. Для каждого элемента:
- если он больше `first`, то `second = first`, `first = текущий`;
- иначе если он меньше `first`, но больше `second`, то `second = текущий`.

Если в массиве все элементы одинаковы (или элементов меньше 2), второго по величине нет.

### Список идентификаторов

| Имя переменной | Тип данных | Смысловое обозначение |
|---|---|---|
| `n` | `int` | Количество элементов |
| `arr` | `int[100]` | Массив |
| `i`, `j` | `int` | Индексы для проверки палиндрома |
| `is_palindrome` | `int` | Флаг (1 — палиндром, 0 — нет) |
| `first` | `int` | Максимальный элемент |
| `second` | `int` | Второй по величине элемент |
| `all_equal` | `int` | Флаг: все ли элементы одинаковы |

### Код программы

```c
#include <stdio.h>

int main(void)
{
    int n;
    printf("Введите количество элементов: ");
    scanf("%d", &n);

    int arr[100];
    printf("Введите %d элементов:\n", n);
    for (int i = 0; i < n; i++) {
        scanf("%d", &arr[i]);
    }

    int is_palindrome = 1;
    for (int i = 0, j = n - 1; i < j; i++, j--) {
        if (arr[i] != arr[j]) {
            is_palindrome = 0;
            break;
        }
    }

    if (n == 0) {
        is_palindrome = 1;
    }

    if (is_palindrome) {
        printf("Массив является палиндромом.\n");
    } else {
        printf("Массив НЕ является палиндромом.\n");
    }

    int first = arr[0], second = -2147483647; /* INT_MIN */
    int all_equal = 1;

    for (int i = 1; i < n; i++) {
        if (arr[i] != arr[0]) {
            all_equal = 0;
        }
        if (arr[i] > first) {
            second = first;
            first = arr[i];
        } else if (arr[i] < first && arr[i] > second) {
            second = arr[i];
        }
    }

    if (n <= 1 || all_equal) {
        printf("Второго по величине элемента нет (все значения одинаковы или элементов мало).\n");
    } else {
        printf("Второй по величине элемент: %d\n", second);
    }
    return 0;
}
```

### Результаты выполненной работы

```
Введите количество элементов: 5
Введите 5 элементов:
1 2 3 2 1
Массив является палиндромом.
Второй по величине элемент: 2
```

**Пояснение:** массив `1 2 3 2 1` читается одинаково с обеих сторон — палиндром. Максимум `first = 3`, второй по величине `second = 2`. Программа корректно определила оба значения.

- реализация сортировки вставками без сторонних функций;
- алгоритмы проверки палиндрома и поиска второго по величине элемента.

Все программы успешно скомпилированы (GCC) и выполнены; результаты корректны и совпадают с ожидаемыми.
